# Forward Deployed Engineer Full Course

A hands-on learning repo for building practical AI-powered applications, following the FDE curriculum from [Coder Army](https://www.youtube.com/@CoderArmy9).

YouTube playlist:
[https://www.youtube.com/watch?v=kBM5UXRbo3U&list=PLWSlr9idVBc0](https://www.youtube.com/watch?v=kBM5UXRbo3U&list=PLWSlr9idVBc0)

## Overview

This repository contains notes, experiments, and mini-projects focused on understanding how LLMs work and how to integrate them into real applications.

The course is structured around practical learning:

- **01-intro**
  - Introductory concepts and project context
- **02-how-llms-actually-work**
  - How large language models work under the hood
- **03-integrating-llm-with-your-application**
  - Building an actual app that calls an LLM and exposes it through an API
- **04-context-window-memory-hallucinations**

## Stack

- **Language:** TypeScript
- **Runtime:** Node.js
- **Framework:** Express
- **LLM provider:** Google Gemini
- **SDK:** @google/genai
- **Environment management:** dotenv
- **Developer tooling:** tsx, TypeScript
